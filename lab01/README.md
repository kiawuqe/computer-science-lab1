\# Лабораторная работа №1: Анализ устройства современной информационной системы



\*\*Цель работы:\*\* Получить представление об устройстве современных информационных систем на примере реальных цифровых сервисов.



\*\*Выбранный цифровой сервис:\*\* Вариант 5 — SaaS-сервис Notion.



\*\*Краткое описание результата:\*\* Проведен анализ компонентов системы Notion, исследована клиентская часть (HTML/CSS и сетевые запросы) с помощью DevTools, пошагово описан пользовательский сценарий создания страницы и составлена архитектурная схема взаимодействия клиента и сервера.
